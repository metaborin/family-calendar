# 家族カレンダー（最小構成版）

家族の予定を入力して、1か月分を **A4縦1ページ** に印刷するための小さなWebアプリです。

手書きの家族カレンダーをそのままパソコンで置き換えることを目的にしています。
会員登録もログインも不要で、入力した内容は**お使いのブラウザの中だけ**に保存されます。

---

## 1. 公開版（GitHub Pages）

インストール不要で、次のURLからすぐに使えます。

**https://metaborin.github.io/family-calendar/**

### 開き方

1. 上のURLをブラウザで開きます。
2. すぐに今月のカレンダーが表示されます。準備や設定は必要ありません。
3. よく使う場合はブックマーク（iPhoneなら「ホーム画面に追加」）しておくと便利です。

### 対応している端末

| 端末 | 使い方 |
| --- | --- |
| パソコン（Windows / Mac） | そのまま利用できます。印刷にも対応しています。 |
| iPhone / Android | 表示・入力できます。**表は左右に指でスクロール**してご覧ください。 |
| iPad / タブレット | 表示・入力できます。同じく横スクロールで全体を確認できます。 |

画面が狭い端末では、6列すべては一度に表示されません。
**表の上を左右にスクロール**すると、隠れている家族の列を確認できます。
（今回はスマートフォン専用の画面は用意していません）

## 2. アプリとしてインストールする（PWA）

このアプリは **PWA（Progressive Web App）** に対応しています。
ホーム画面やスタートメニューへ追加すると、**アプリのアイコンから直接起動**でき、
対応端末では**アドレスバーの出ない全画面**で使えます。

**インストールしなくても、ブラウザでそのまま使えます。** 好みで選んでください。

> App Store や Google Play から入れるアプリではありません。
> 公開URLをブラウザで開いて「ホーム画面に追加」する方式です。

画面上部の「**アプリとして使う**」ボタンを押すと、お使いの端末向けの手順が表示されます。

### iPhone・iPad（Safari）

1. **Safari** で https://metaborin.github.io/family-calendar/ を開く
2. 画面下（iPadは画面上）の**共有ボタン**（□に↑）を押す
3. 「**ホーム画面に追加**」を選ぶ
4. 「Webアプリとして開く」に相当する設定が表示される場合は**有効にする**
5. 「**追加**」を押す

※ Chrome など Safari 以外のブラウザからは追加できません。

### Android（Chrome）

1. Chrome で公開URLを開く
2. 右上のメニュー（︙）を開く
3. 「**アプリをインストール**」または「**ホーム画面に追加**」を選ぶ

### Windows の Chrome

1. Chrome で公開URLを開く
2. アドレスバー右側の**インストールアイコン**を押す
3. または、メニュー（︙）→「キャストして保存して共有」→「**アプリをインストール**」

### Windows の Edge

1. Edge で公開URLを開く
2. アドレスバー右側の**インストールアイコン**を押す
3. または、メニュー（…）→「アプリ」→「**このサイトをアプリとしてインストール**」

### オフラインで使う

**最初に一度、オンラインの状態で開いてください。**
そのときにアプリ本体（画面・デザイン・アイコン）が端末へ保存されます。

一度開いたあとは、**電波やWi-Fiがなくてもアプリを起動して使えます。**

オフラインでできること：

- アプリを起動する
- 保存済みの予定・家族名を表示する
- 前月・次月へ移動する、年月を変更する
- 予定を入力・変更する（そのまま端末へ保存されます）
- 家族名を変更する
- 印刷ボタンを押す

オフライン中は、画面上部に小さく「**オフライン**」と表示されます。
通信が戻れば自動的に消えます。

オフライン時の制限：

- **アプリの更新は受け取れません**（オンラインに戻ったときに確認されます）
- 初回の起動だけはオンラインが必要です
- 印刷は端末とプリンターの接続状況によります（PDF保存は可能です）

### アプリの更新について

新しいバージョンを公開すると、次にオンラインでアプリを開いたときに
画面右下へ小さく「**新しいバージョンがあります。**」と表示されます。

- 「**更新する**」を押すと、その場で最新版に切り替わります
- 「**後で**」を押すと、そのまま今のバージョンを使い続けられます

**入力中に勝手に再読み込みされることはありません。** 更新はボタンを押したときだけ行われます。

### アンインストールする方法

| 端末 | 手順 |
| --- | --- |
| iPhone・iPad | ホーム画面のアイコンを長押し →「Appを削除」→「ホーム画面から取り除く」または「Appを削除」 |
| Android | ホーム画面のアイコンを長押し →「アンインストール」 |
| Windows Chrome | アプリを開く → 右上メニュー（︙）→「家族カレンダーをアンインストール」 |
| Windows Edge | Edge の `edge://apps` を開く → 対象アプリの「…」→「アンインストール」 |

**アンインストールすると、そのアプリに保存されていた予定も一緒に消える場合があります。**
大切な予定は、事前に印刷またはPDF保存で残しておいてください。

## 3. 月ごとのイラストとデザイン

カレンダー上部に、**月ごとの小さな季節イラスト**が表示されます。

- **月を変えると、イラストが自動で切り替わります**（1月〜12月で12種類）
- あわせて、見出しやボタンの**アクセントカラーも季節に合わせて少しだけ変わります**
- 設定は不要です。表示中の月から自動的に決まります

| 月 | イラスト | 月 | イラスト |
| --- | --- | --- | --- |
| 1月 | 雪の結晶・梅・結び飾り | 7月 | 笹・短冊・星と月 |
| 2月 | 雪・手袋・梅 | 8月 | ひまわり・日差し・花火 |
| 3月 | 春の風・桜のつぼみ・小鳥 | 9月 | 月・すすき・秋の雲 |
| 4月 | 桜・若葉・蝶 | 10月 | どんぐり・紅葉・木の実 |
| 5月 | こいのぼり・新緑・風 | 11月 | いちょう・落ち葉・秋の風 |
| 6月 | あじさい・傘・雨粒 | 12月 | 雪の結晶・木・冬の飾り |

### 大事にしていること

**家族の予定が読みやすいことが最優先です。** イラストや色は、予定表より目立たないようにしています。

- イラストは**カレンダー上部だけ**に置いています。表のマス目の中には入りません
- 予定の文字の大きさ・色・行の高さは**これまでどおり**です
- **土曜日の水色・日曜日のピンクは、月によって変わりません**（いつも同じです）
- 予定6列の均等な幅、日付欄の幅も変わりません

> 月テーマの色は、月ヘッダー・操作部の区切り線・ボタンへ控えめに適用されます。
> 「予定を追加」ボタンだけは、白文字が全12か月で読みやすいよう少し濃い色を使っています。
> **月別イラストや予定データには影響しません。**

### イラストについて

- すべて**このアプリのために描いた完全オリジナルのSVG**です
- **外部の画像サービスやインターネット上の素材は一切使っていません**
  （アプリの中にすべて入っているので、通信は発生しません）
- **オフラインでも12か月すべてのイラストが表示されます**
- **イラストはユーザーが変更・追加・非表示にすることはできません**（今回は固定です）
- **予定データやlocalStorageには一切影響しません**

### 印刷について（期間予定を含む）

イラストは**印刷にも小さく表示されます**（タイトルの右側）。

ただし **A4縦1ページに収めることを最優先**しているため、
印刷時のイラストは画面よりかなり小さく（横22mm・縦9mm程度）なります。
予定表の行の高さや予定の文字サイズは、イラストのために小さくすることはありません。

**期間予定も印刷されます。**

- 開始日から終了日まで、**細い縦線（約1.7pt）がつながって**印刷されます
- 開始部分・終了部分・前月からの継続・翌月への継続も、印刷で分かります
- 予定名は、その月で最初に見える日に印刷されます
- 期間予定のために、行の高さ・日付や予定の文字サイズ・列幅・余白は変えていません
- **期間予定が多いと、印刷時に窮屈になる**ことがあります。
  同じ日にたくさん重なると画面に注意が表示されますが、
  **登録したデータが削除されることはありません**（画面上ではすべて確認・編集できます）

## 4. バックアップと復元

予定はこの端末の中だけに保存されるため、**サイトデータの削除やアプリの削除で消えてしまいます。**
大切な予定は、ときどきバックアップを保存しておくことをおすすめします。

### バックアップを保存する

1. 画面上部の「**バックアップ**」を押す
2. 「**バックアップを保存**」を押す
3. JSONファイルがダウンロードされるので、**安全な場所へ保存**する

ファイル名の例：

```text
家族カレンダー_2026-08-20_203045.json
```

バックアップに含まれるもの（**5種類すべて**）：

- 家族名
- 自由入力メモ
- 時間付き予定
- 毎週の定期予定と「この日だけ休み」の設定
- **期間予定**（複数日にわたる予定）

新しく作成するバックアップの形式は **schemaVersion 2** です。
期間予定を追加したことにともなって 1 から 2 へ上げました。

> **このファイルには家族名や予定などの個人情報が含まれます。**
> 第三者と共有せず、安全な場所に保管してください。
> ファイルは端末内で作られるだけで、**GitHubや外部のサーバーへ送信されることはありません**。

### バックアップから復元する

1. 画面上部の「**バックアップ**」を押す
2. 「**ファイルを選ぶ**」を押して、保存したJSONファイルを選ぶ
3. 内容の概要（作成日時・件数・対象期間）が表示されるので確認する
4. 「**このバックアップで復元する**」を押す

> **復元すると、この端末に現在保存されている家族名と予定は、
> バックアップの内容ですべて置き換わります。**
> 必要な場合は、復元する前に現在のデータをバックアップしてください。

壊れたファイルや別のアプリのJSONを選んだ場合は、**復元されず、現在のデータも変わりません。**
理由が日本語で表示されるので、正しいファイルを選び直してください。

#### 以前のバックアップ（schemaVersion 1）について

期間予定を追加する前に保存したバックアップ（**schemaVersion 1**）も、**そのまま復元できます**。
ただし、そのファイルには期間予定が入っていません。

復元前のプレビューに、次の警告が表示されます。

```text
このバックアップは旧形式です。
期間予定は含まれていません。

復元すると、この端末に現在登録されている期間予定はすべて削除されます。
```

- 復元は**全置換**です。旧形式を復元すると、**現在の期間予定はすべて消えます**
  （現在の期間予定だけを残して混ぜる、という動作はしません）
- 心配な場合は、**復元する前に現在のデータをバックアップ**してください
  （新しく保存すれば schemaVersion 2 になり、期間予定も含まれます）
- 現在のアプリより**新しい形式**（schemaVersion 3 以上）のファイルは、
  誤って古い形へ書き戻さないよう**復元を断ります**
- バックアップは**手動**です。自動同期ではありません

### 別の端末へ移す（手動）

バックアップファイルを使うと、次のような移動ができます。

- パソコン → iPhone
- iPhone → パソコン
- Chrome → Edge
- Safari → ホーム画面に追加したアプリ
- 古い端末 → 新しい端末

手順：

1. 元の端末でバックアップを保存する
2. JSONファイルを安全な方法で新しい端末へ移す（USBメモリ、自分宛のメールなど）
3. 新しい端末で家族カレンダーを開く
4. 「バックアップ」から「ファイルを選ぶ」でファイルを選ぶ
5. 内容を確認して復元する

> **これは自動同期ではありません。**
> 復元したあとの変更は、これまでどおり端末ごとに別々に保存されます。
> 両方の端末を同じ状態に保ち続ける機能ではありません。
> また、**移行先の端末にあったデータは復元によって置き換わります。**

### 注意事項

- バックアップファイルには**個人情報が含まれます**。安全な場所へ保管してください
- **サイトデータを削除する前**、**アプリを削除する前**にバックアップしてください
- 定期的なバックアップをおすすめします
- 復元は**全置換**です。今あるデータと混ぜる（マージする）機能はありません
- 月単位・家族単位の部分復元はできません
- 壊れたファイルは復元しません（現在のデータは守られます）
- **オフラインでもバックアップ・復元ができます**
- 新しい形式で作られたバックアップは、古いアプリでは復元できない場合があります
- App Store や Google Play のクラウドバックアップとは関係ありません

## 5. 予定はどこに保存されるのか（とても重要）

入力した予定と家族名は、**その端末のそのブラウザの中（localStorage）だけ**に保存されます。
インターネット上のサーバーやGitHubには、**一切送信されません**。

そのため、次のような動作になります。**これは不具合ではなく仕様です。**

| 項目 | 動作 |
| --- | --- |
| パソコンで入力した予定 | **そのパソコンのそのブラウザにだけ**保存されます |
| iPhoneで入力した予定 | **そのiPhoneのそのブラウザにだけ**保存されます |
| 端末をまたいだ同期 | **されません**（PCで入力した予定はiPhoneには出ません） |
| 別のブラウザ | **引き継がれません**（Chromeの予定はEdgeには出ません） |
| 他の人が公開URLを開いたとき | **あなたの予定は見えません**（その人の端末には空のカレンダーが出ます） |
| ページの再読み込み | その端末の予定は**残ります** |
| ブラウザのサイトデータを削除 | 予定も**消えます** |
| GitHubへのデータ送信 | **ありません**（ログイン・サーバー・データベースがないため） |

### localhost版から公開版への引き継ぎについて

パソコンで `http://localhost:5173/` を使って入力していた予定は、
**公開版（GitHub Pages）へは自動で引き継がれません。**

localStorage は「どのサイトか」ごとに別々に保存されるため、
`localhost` と `metaborin.github.io` は別のサイトとして扱われます。
公開版を使い始める場合は、お手数ですが改めて入力してください。

### インストールしたアプリとブラウザのデータについて

PWA化しても、予定の保存先は**これまでと同じ localStorage のまま**です。
保存キーもデータの形も変更していないため、**すでに入力済みの予定はそのまま残ります。**

ただし、次の点にご注意ください。

- **iPhone・iPad では、Safari で入力済みの予定が、ホーム画面へ追加したアプリへ
  自動コピーされない場合があります。** iOS の仕様上、
  Safari とホーム画面Webアプリで保存領域が分かれることがあるためです。
  この動作は端末・iOSバージョンによって異なり、**確実に引き継げる保証はありません。**
  ホーム画面アプリで空のカレンダーが出た場合は、お手数ですが改めて入力してください。
- 同じ理由で、**ブラウザ版とインストール版で予定が別々になる場合があります。**
- **アプリをアンインストール（ホーム画面から削除）すると、
  そのアプリに保存されていた予定も消える場合があります。**
- ブラウザのサイトデータ削除でも予定は消えます。
- Service Worker の更新やキャッシュの入れ替えでは、**予定は消えません**
  （Service Worker が扱うのはアプリ本体のファイルだけで、入力データには触れません）。

> 大切な予定は、**バックアップ**（上の「4. バックアップと復元」）で
> JSONファイルへ保存しておくことをおすすめします。印刷やPDF保存も有効です。

使用しているlocalStorageキー：

| キー | 内容 |
| --- | --- |
| `family-calendar-mvp:names` | 家族の表示名 |
| `family-calendar-mvp:schedules` | **自由入力メモ**（年月ごと） |
| `family-calendar-mvp:timed-events` | **時間付き予定**（年月ごと） |
| `family-calendar-mvp:recurring-rules` | **毎週の定期予定のルール** |
| `family-calendar-mvp:range-events` | **期間予定**（開始日〜終了日） |

自由入力メモの保存される形（従来どおり）：

```json
{
  "2026-08": {
    "1": { "everyone": "買い物", "member1": "仕事" }
  }
}
```

期間予定の保存される形：

```json
[
  {
    "id": "range-example-1",
    "columnId": "member1",
    "title": "夏季保育",
    "startDate": "2026-08-03",
    "endDate": "2026-08-07"
  }
]
```

> 時間付き予定・定期予定・期間予定は、それぞれ**別のキー**に保存しています。
> 自由入力メモのデータ（`family-calendar-mvp:schedules`）は形も中身も変えていないため、
> **以前から入力していた予定はそのまま残ります。** 移行作業は不要です。

なお、**毎週の定期予定は各月へコピーされません。** ルールだけを保存しておき、
表示するたびに「その月のどの日に当たるか」を計算しています。
そのためルールを直すと、該当するすべての日へすぐ反映されます。

**期間予定も同じ考え方**です。各日へ複製せず、開始日と終了日の1件だけを保存し、
表示するたびに「その月と重なる日」を計算しています。
月や年をまたぐ予定も、データは1件のままです。

保存データが壊れて読み込めなかった場合も、アプリが真っ白になることはありません。
初期値で起動し、画面上部にエラーメッセージを表示します。

## 6. できること

- 1日から月末までを縦に並べた予定表を表示する
- 「みんなの予定」＋家族5人分、合計6列に予定を入力する
- **時間付きの予定**（例：`09:30–10:30 病院`）を日付を指定して追加する
- **毎週の定期予定**（例：毎週火曜 `17:00–18:00 ピアノ`）を登録して自動表示する
- 定期予定を**「この日だけ休み」**にする（休講日・祝日など）
- **期間予定**（例：8月3日〜7日 夏季保育）を登録し、縦の帯でつながって表示する
- 期間予定が月や年をまたいでも、1件のデータのまま両方の月へ表示する
- 重なった期間予定を別のレーンへ自動で振り分ける
- 予定を**開始時間の早い順**に並べて表示する
- 時間の決まっていないことは、これまでどおり**自由入力メモ**に書く
- 入力すると自動で保存される（保存ボタンは不要）
- 家族の表示名を自由に変更できる
- 前月・次月へ移動する、年と月を直接指定する
- 土曜日を薄い水色、日曜日を薄いピンクで色分けする
- 1か月分をA4縦1ページへ印刷する（PDF保存も可能）
- インストールしてアプリのように使う／オフラインで使う（PWA）
- 月ごとに小さな季節イラストとアクセントカラーが自動で変わる
- 予定をまとめてJSONファイルへバックアップし、別の端末へ手動で移せる

## 7. 使用技術

| 項目 | 内容 |
| --- | --- |
| 画面 | React 19 + TypeScript |
| ビルド | Vite |
| スタイル | 通常のCSS（画面用 `App.css` / 印刷用 `print.css` / PWA用 `pwa/pwa.css` / 予定用 `events/events.css`） |

## 9. 使い方

### 7-1. 家族名を変更する

画面上部の「**家族名の変更**」欄にある6つの入力欄を書き換えてください。

- 1列目：みんなの予定（家族全員の予定・行事・祝日など）
- 2〜6列目：家族それぞれの予定

書き換えた名前はすぐに保存され、表の見出しにも反映されます。

**名前を変えても、入力済みの予定は消えません。別の列へ移動することもありません。**
予定は表示名ではなく、内部の固定ID（`everyone` / `member1`〜`member5`）で管理しているためです。

### 7-2. 予定の4つの入れ方

この家族カレンダーには、予定の入れ方が4つあります。用途に合わせて使い分けてください。

| 入れ方 | 向いている予定 | 例 |
| --- | --- | --- |
| **自由入力メモ** | 時間が決まっていないこと・ひとこと書いておきたいこと | 学校行事、ゴミ出し |
| **時間付き予定** | その日だけの、時間が決まっている予定 | 8月5日 09:30–10:30 病院 |
| **毎週の定期予定** | 曜日が決まっていて毎週くり返すもの | 毎週火曜 17:00–18:00 ピアノ |
| **期間予定** | 何日も続く終日の予定 | 8月3日〜7日 夏季保育 |

同じセルの中に、4つとも一緒に入れられます。表示は次の順番になります。

```text
┌ 夏季保育              ← 期間予定（左端の縦帯でつながって見える）
│ 09:30–10:30 病院      ← 時間付き予定
│ 17:00–18:00 ピアノ ↻  ← 毎週の定期予定（↻ が繰り返しの印）
│ 学校行事              ← 自由入力メモ
```

時間付き予定と定期予定は**開始時間の早い順**に並びます。時間を入れなかった予定は、時間付きの予定より後に並びます。
期間予定は時間を持たないため、いちばん上（左端の縦帯）に表示されます。

### 7-3. 時間付き予定（その日だけの予定）

#### 追加する

方法は2つあります。

- 画面上部の「**予定を追加**」ボタンを押す
- 表のセルの右上に出る「**＋**」を押す（日付と家族が最初から選ばれた状態で開きます）

入力する項目：

| 項目 | 説明 |
| --- | --- |
| 予定名 | **必須**です（例：病院、ピアノ） |
| 日付 | いつの予定か |
| 対象 | どの家族の列に入れるか（「みんなの予定」も選べます） |
| 開始時間 | 24時間表記（例：`09:30`）。**空欄でも構いません** |
| 終了時間 | 任意。開始時間を入れたときだけ入力できます |

表示のされ方：

- 開始・終了あり → `15:30–16:30 ピアノ`
- 開始だけ → `15:30 ピアノ`
- 時間なし → `ピアノ`

> 終了時間が開始時間より前だと、エラーが出て保存されません。
> 入力した内容が勝手に書き換えられたり消されたりすることはありません。

#### 1日にいくつも入れる

同じ日・同じ家族に、いくつでも予定を追加できます。開始時間の早い順に並びます。

```text
09:00–10:00 歯医者
15:30–16:30 ピアノ
18:00 買い物
```

#### 編集・削除する

表に出ている予定を**タップ（クリック）**すると、編集画面が開きます。

- 予定名・日付・対象・開始時間・終了時間を変更できます
- **日付や対象を変えると、その予定は変更後のセルへ移動します**
- 「**削除**」を押すと削除できます（削除前に確認が出ます）

### 7-4. 毎週の定期予定（習い事など）

ピアノ教室や水泳教室のように、**毎週決まった曜日**に繰り返す予定を登録できます。
一度登録すれば、**その曜日に自動で表示され続けます**。月をめくっても、年をまたいでも自動で出ます。

#### 追加する

1. 画面上部の「**定期予定**」ボタンを押す
2. 「**新しい定期予定を追加**」を押す
3. 次を入力して「保存」

| 項目 | 説明 |
| --- | --- |
| 予定名 | **必須**（例：ピアノ） |
| 対象 | どの家族の列に入れるか |
| 曜日 | 日〜土から**1つ**選ぶ |
| 開始時間 | 任意（例：`17:00`） |
| 終了時間 | 任意 |
| 開始日 | **必須**。この日から表示が始まります（開始日当日も含みます） |
| 終了日 | **空欄なら終了日なし**（ずっと繰り返します）。入れた場合はその日まで（当日も含みます） |
| 有効・無効 | チェックを外すと、消さずに表示だけ止められます |

> 曜日は1つの定期予定につき1つです。
> 火曜と木曜の両方に入れたい場合は、**火曜用と木曜用の2つ**を登録してください。

#### 編集・無効化・削除する

「定期予定」ボタンを押すと、登録済みの一覧が出ます。各行に次のボタンがあります。

- **編集** … 内容を直す（直すと、該当するすべての日へすぐ反映されます）
- **無効にする / 有効にする** … 削除せずに表示だけ止める・再開する
- **削除** … 完全に削除する（確認が出ます）

登録がまだない場合は「定期予定はまだ登録されていません。」と表示されます。

### 7-5. 期間予定（複数日にわたる予定）

#### 期間予定とは

**開始日から終了日まで、何日も続く終日の予定**です。
たとえば「8月3日〜8月7日 夏季保育」「7月30日〜8月4日 家族旅行」のように、
1件登録するだけで、その期間のすべての日へ縦の帯が表示されます。

```text
8月3日  ┌ 夏季保育
8月4日  │
8月5日  │
8月6日  │
8月7日  └
```

各日へ予定をコピーしているわけではありません。
**開始日と終了日の1件だけを保存**し、表示のたびに「その月と重なる日」を計算しています。
そのため、あとから期間を変えれば、すべての該当日へすぐ反映されます。

#### 追加する

1. 画面上部の「**期間予定**」を押す
2. 「**新しい期間予定を追加**」を押す
3. 次を入力する
   - **予定名**（必須。例：夏季保育）
   - **対象**（みんなの予定／家族1〜家族5から選ぶ）
   - **開始日**（必須）
   - **終了日**（必須）
4. 「**保存**」を押す

終了日が開始日より前のときは保存できません。
その場合は次のように表示されます。

```text
終了日は開始日以降の日付を指定してください。
```

#### 同じ日だけの期間予定

開始日と終了日を**同じ日**にすれば、1日だけの期間予定として登録できます。
その日は上下とも丸い帯で表示されます。

時間を決めたい1日の予定であれば、「**予定を追加**」（時間付き予定）のほうが向いています。
開始日と終了日が同じときは、その案内が画面にも表示されます。

#### 編集・削除する

編集画面は3か所から開けます。

- カレンダーの**予定名ラベル**を押す
- カレンダーの**縦帯**を押す（帯の見た目は細いですが、押せる範囲は広めにしてあります）
- 「**期間予定**」ダイアログの一覧から「**編集**」を押す

編集できるのは、対象・予定名・開始日・終了日です。
削除は、一覧の「**削除**」または編集画面の「**削除**」から行います。
削除前には確認が表示され、削除すると**すべての該当日から消えます**。

#### 月をまたぐ予定・年をまたぐ予定

期間が月や年をまたいでも、そのまま登録できます。

```text
7月30日  ┌ 家族旅行
7月31日  │ ↓        ← 翌月へ続く印

8月1日   │ 家族旅行（前月から）
8月2日   │
8月3日   │
8月4日   └
```

- **前月以前から続いている予定**は、その月で最初に見える日に「**（前月から）**」付きで表示されます
- **翌月以降へ続く予定**は、その月で最後に見える日の帯の下に**小さな下向きの印**が付きます
- 年をまたぐ場合（例：2026年12月29日〜2027年1月3日）も同じように表示されます
- うるう年の2月29日にも対応しています

予定名ラベルは、**その月で最初に見える日にだけ**表示されます。
中間の日は帯だけになるため、行の高さは増えません。

#### 重なった期間予定は別のレーンに表示される

同じ家族の列で期間が重なった場合、帯が同じ位置に描かれないよう、
**左から順に別のレーン（縦のすじ）へ自動で振り分け**られます。

```text
8月3日  ┌予定A
8月4日  │
8月5日  │ ┌予定B
8月6日  │ │ ┌予定C
8月7日  └ │ │
8月8日    │ └
8月9日    └
```

- レーンの数は固定ではなく、必要な分だけ増えます
- 重ならない期間では、同じレーンを使い回します
- 色は予定ごとに自動で決まり、**月を移動しても再読み込みしても変わりません**
- 同じ日にたくさん重なると、画面に小さな注意が表示されます
  （**登録した予定が消えることはありません**）

#### 期間予定には時間を設定しません

期間予定は**終日の予定**として扱うため、開始時間・終了時間は設定できません。

| | 期間予定 | 時間付き予定 |
| --- | --- | --- |
| 日数 | 何日でも（開始日〜終了日） | 1日だけ |
| 時間 | 設定しない | 開始時間・終了時間を設定できる |
| 表示 | 左端の縦帯＋予定名 | `09:30–10:30 病院` |
| 向いている予定 | 夏季保育、家族旅行、年末年始休業 | 病院、面談、習い事の振替 |

時間を指定したい1日の予定には「**予定を追加**」を、
毎週くり返す予定には「**定期予定**」をお使いください。

### 7-6. 「この日だけ休み」にする（休講日・祝日など）

習い事が休みの日は、定期予定を消さずにその日だけ非表示にできます。

1. カレンダーに出ている**定期予定（↻ が付いているもの）をタップ**する
2. 「**この日だけ休みにする**」を選ぶ

#### 元に戻す

1. 「定期予定」ボタン →「編集」を開く
2. 下の「**休みにした日**」に、休みにした日が一覧で出ます
3. 戻したい日の「**元に戻す**」を押して「保存」

```text
休みにした日
2026年8月11日　元に戻す
2026年9月22日　元に戻す
```

#### その日だけ時間を変えたいとき

1回だけ時間を変える機能はありません。次の手順で対応してください。

1. その日を「**この日だけ休みにする**」
2. 同じ日に「**時間付き予定**」を追加する

### 7-7. 自由入力メモ（これまでどおり）

セルの下側にある入力欄は、これまでどおり自由に文字を入力できます。

- 日本語入力（かな漢字変換）が使えます
- `Enter` で改行できます
- コピー＆貼り付けができます
- **保存ボタンはありません。入力するとすぐ自動保存されます**
- 入力中のセルは水色の枠で表示されます

祝日や行事など、時間の決まっていないことはここへ書いてください。

### 7-8. 月を変更する

画面上部で操作します。

- 「**前月**」「**次月**」ボタン … 1か月ずつ移動します（年をまたぐ移動にも対応）
- 「**年**」欄 … 年を直接入力します
- 「**月**」欄 … 月を選びます

月が変わっても、それぞれの月の予定は別々に保存されています。混ざることはありません。

### 7-9. 印刷する

1. 印刷したい年月を表示します。
2. 画面右上の「**印刷**」ボタンを押します。
3. ブラウザの印刷画面が開きます。次の設定を確認してください。

   | 項目 | 設定 |
   | --- | --- |
   | 用紙サイズ | **A4** |
   | 印刷の向き | **縦** |
   | 倍率 | **既定 / 100%**（「用紙に合わせる」でも可） |
   | 背景のグラフィック | **オン**（土日の色を印刷する場合） |

4. 「印刷」を押します。

操作ボタン・年月の選択欄・家族名の変更欄は印刷されません。
印刷されるのは、タイトル「家族カレンダー」、選択中の年月、家族名、日付、曜日、入力した予定です。

### 7-10. PDFとして保存する

印刷画面の「**プリンター**」の選択肢で、

- Google Chrome：「**PDFに保存**」
- Microsoft Edge：「**PDFとして保存**」

を選んで保存してください。紙に印刷する場合と同じレイアウトで保存できます。

### 7-11. 印刷しても土日の色が出ないとき

ブラウザの印刷画面で、次を確認してください。

- Chrome / Edge：「**詳細設定**」を開き、「**背景のグラフィック**」にチェックを入れる
- Firefox：「**背景色と背景画像を印刷**」にチェックを入れる

アプリ側では `print-color-adjust: exact` を指定していますが、
最終的には**ブラウザの印刷設定が優先される**ため、上記の確認が必要です。

## 10. GitHub Pages への公開について

### 仕組み

`main` ブランチへ push すると、GitHub Actions が自動で次を実行して再公開します。

1. ソースを取得（checkout）
2. Node.js 22 をセットアップ
3. `npm ci`（依存関係のインストール）
4. `npm run lint`
5. `npm run build`
6. `dist` フォルダを Pages 用の成果物としてアップロード
7. GitHub Pages へデプロイ

ワークフローの定義：`.github/workflows/deploy-pages.yml`

**公開されるのはビルド結果（`dist`）だけ**で、`node_modules` やプロジェクト全体は公開されません。

### 再公開する方法

```bash
git add .
```

```bash
git commit -m "Update calendar"
```

```bash
git push
```

push の1〜3分後に公開版へ反映されます。

手動で実行したい場合は、GitHubのリポジトリ画面で
**Actions** → **Deploy to GitHub Pages** → **Run workflow** から実行できます。

### デプロイが失敗したときの確認場所

1. GitHubでリポジトリを開く
2. 上部の **Actions** タブを開く
3. 失敗した実行（赤い×印）をクリック
4. **build** または **deploy** のジョブを開き、赤くなっているステップのログを確認

よくある原因：

- `npm run lint` でエラーが出ている（コードの書き方の問題）
- `npm run build` で型エラーが出ている
- Pages の設定が **GitHub Actions** になっていない
  （Settings → Pages → Build and deployment → Source）

## 11. 現在の制限事項

- **長い文章はA4印刷時に収まりにくい**です。
  1ページに1か月分を収めるため、1行の高さは自動的に小さくなります（31日の月で約8.6mm）。
  1セルにはおおよそ **10〜20文字程度の短い予定** を入力する前提でお使いください。
  長すぎる文章を入れると、印刷時に文字が隠れたり、行の高さが伸びて
  1ページに収まらなくなることがあります。
  なお、**保存されているデータ自体が削られることはありません**（画面上では全文を確認できます）。
- **祝日の自動表示には対応していません。**
  祝日・行事は「みんなの予定」欄へ手で入力してお使いください。
- **端末間で予定は同期されません**（上の「5. 予定はどこに保存されるのか」を参照）。
- **スマートフォン専用の画面はありません。** 狭い画面では表を横スクロールしてお使いください。
- 印刷は主にパソコンでの利用を想定しています。
- **オフラインで使うには、最初に一度オンラインで開く必要があります。**
- **バックアップは手動です。** 自動バックアップや自動同期はありません。
  端末が壊れた場合やアプリを削除した場合に備え、ときどき手動でバックアップしてください。
- **復元は全置換です。** 今あるデータと混ぜる（マージする）機能はありません。
- **以前のバックアップ（schemaVersion 1）には期間予定が含まれていません。**
  そのファイルを復元すると、**現在の期間予定はすべて消えます**（復元前に警告が出ます）。
- **繰り返しは「毎週・1曜日」だけに対応しています。**
  隔週、第1・第3◯曜日、毎月、毎年、平日のみ、1つのルールへ複数曜日、
  祝日は自動で休みにする、といった繰り返しには**対応していません**。
  複数の曜日に入れたい場合は、曜日ごとに定期予定を登録してください。
- **1つの予定が日付をまたぐこと（例：22:00〜翌01:00）には対応していません。**
  複数日にわたる予定には「**期間予定**」をお使いください（終日の予定として扱います）。
- **期間予定に時間は設定できません。** 終日の予定として扱います。
- **期間予定の色は自分で選べません。** 予定ごとに自動で決まります
  （同じ予定なら、月を移動しても再読み込みしても同じ色です）。
- **同じ日に期間予定が多く重なると、印刷時に見分けにくくなる**ことがあります。
  画面には注意が表示されますが、データが削除されることはありません。
- **1日にたくさんの予定を入れると、印刷時に一部が表示されない場合があります。**
  A4縦1ページに収めるため、1行の高さは月の日数から自動計算しており
  （31日の月で約8.6mm）、そこへ収まらない分は印刷時に隠れます。
  予定が多い月は、画面上に小さな注意が表示されます。
  **隠れるのは印刷時の見た目だけで、保存したデータが消えることはありません**
  （画面上ではすべて確認・編集できます）。
- **App Store・Google Play で配信しているアプリではありません。**
  ブラウザから「ホーム画面に追加」でインストールする方式です。

## 15. ライセンス・素材について

- このアプリは家庭内で使うことを目的に作られています。
- 参考にした手書きカレンダーの原本、そこに含まれるイラスト・ロゴ・ブランド名などの
  第三者の素材は、このリポジトリには **一切含まれていません**。
- 画面のレイアウト（列構成、1日〜月末を縦に並べる形式、土日の色分け）のみを
  参考にして、コードとスタイルはすべて新規に作成しています。
- 月別イラスト12点も、SVGの基本図形（円・線・パスなど）だけで新規に作成した
  完全オリジナルです。参照PDFのイラストや、インターネット上・フリー素材サイトの
  画像は一切使用していません。
